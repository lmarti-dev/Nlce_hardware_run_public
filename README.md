

# What is this?

This library implements code and stores data related to the work 

[Thermodynamic-limit dispersion relations on trapped-ion quantum hardware](https://arxiv.org/abs/2605.28599)

In src/qcomp_nlce/plots/ all the plots in the paper can be reproduced. The data lives in qcomp_nlce/data.

Requirements depend on which quantum hardware is used (and whether uv is used to run the project).
